节奏榜（Tier Maker）把本站收录的全部卡片放进一个可以自由编辑的榜单。所有操作都在浏览器里完成，榜单自动保存在本机，不会上传到服务器。

## 打开节奏榜

从左侧导航或首页的「节奏榜」卡片进入 `/tier`。默认榜单有 S、A、B、C、D、F 六个档位，标题是「我的节奏榜」，可以随时点击标题直接改名。

榜单下方是角色池，包含全部卡片（含皮肤）。已经上榜的卡片仍然留在池中，只是变暗并在右上角显示所在档位，方便你对照。

## 把卡片放进档位

### 拖拽

- 从角色池拖到任意档位，松手即放入该档末尾。
- 在档位之间拖动可以换档，拖动时卡片之间的空隙决定插入位置。
- 在档位内拖动可以调整顺序。
- 键盘操作：Tab 到卡片后按空格或回车拾起，用方向键移动，再按空格或回车放下，按 Esc 取消。
- 触屏需要按住卡片约 200 毫秒再拖动，避免与页面滚动冲突。

### 「＋」菜单

每张卡片右下角都有一个「＋」按钮，点击后列出当前所有档位：

- 选择「放入 X 档」直接归位，不需要拖拽。
- 卡片已在榜上时，菜单最后会多出「移出榜单」，把它放回角色池。

「＋」菜单是键盘和触屏的主要操作路径，菜单打开后可以用方向键在档位之间移动，Esc 关闭并把焦点还给按钮。

## 调整档位

- 点击档位名称即可重命名，回车确认，Esc 取消。
- 每个档位左侧的颜色块可以打开颜色选择器，也可以用预设色板快速换色。
- 档位设置面板里提供「上移」「下移」「删除档位」。
- 最多 12 个档位，至少保留 1 个；删除还有卡片的档位会先确认，并自动保存一份快照，卡片随后回到角色池。
- 「添加档位」在末尾追加一个新档位。
- 「重置」会清空全部放置并恢复默认六个档位，执行前同样会自动保存快照。

## 筛选角色池

角色池上方的工具栏可以按以下条件筛选：

- 关键词：匹配卡片名称，输入停止 150 毫秒后才生效。
- 属性、阵营、职业、星级：每个维度单选，默认「全部」。
- 「仅看未上榜」：只显示还没放进任何档位的卡片。
- 「清空筛选」：一次恢复所有条件。

工具栏会实时显示当前结果数量与已上榜数量。筛选只影响角色池的显示，不会改动榜单内容。

## 保存与快照

每次改动都会自动写入浏览器的本地存储（localStorage），刷新或下次打开页面时自动恢复。如果浏览器禁用了本地存储，页面顶部会出现提示，本次修改不会被保存。

「保存快照」把当前榜单复制进历史记录，「快照历史」里可以查看、恢复或删除。最多保留 20 份，超出后最早的会被移除。重置、导入、删除非空档位这些破坏性操作都会在动手前自动保存一份快照，误操作也能找回。

## 导入与导出

「导出 JSON」下载一个 `bl-tier-YYYYMMDD-HHmm.json` 文件，结构如下：

```json
{
  "format": "bl-tier",
  "version": 1,
  "title": "我的节奏榜",
  "updatedAt": "2026-11-01T12:00:00.000Z",
  "tiers": [
    {
      "id": "t-s",
      "name": "S",
      "color": "#e11d48",
      "cards": [{ "serial": 1020, "name": "月季院" }]
    }
  ]
}
```

「导入」读取同样格式的文件，并用它覆盖当前榜单。导入前会自动保存一份快照。文件里的卡片名称只是便于阅读的快照，展示时始终以本站卡片数据为准；本地不存在的卡片编号会被跳过，重复出现的卡片只保留第一次，页面会给出对应提示。

## 导出 PNG

「导出 PNG」把当前榜单渲染成一张宽 1200 像素、按 2 倍分辨率输出的图片，文件名同样是 `bl-tier-YYYYMMDD-HHmm.png`，适合直接分享。导出时会先把用到的图标下载到本地，避免画布被跨域图片污染；个别图标下载失败会以占位图代替，并在提示里说明数量，不会中断导出。

## 小技巧

- 先把想聊的卡片全部拖进一个档位，再在档位内排序，比来回换档快。
- 用「仅看未上榜」检查有没有漏掉的卡片。
- 想保留多个版本时，用快照而不是导出多个 JSON；快照恢复只需要一次点击。
